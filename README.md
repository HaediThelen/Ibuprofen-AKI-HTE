# Ibuprofen-AKI-HTE
Code for the manuscript "Ibuprofen Use and Acute Kidney Injury Among Adults Admitted to the Hospital"

This repository accompanies a study examining the association between ibuprofen exposure and kidney outcomes among hospitalized patients, and how these relationships vary across patient subgroups.

Manuscript Status:
This work is currently under review for publication.

The associated dataset is available for download at: [10.5281/zenodo.22014670](10.5281/zenodo.22014670)
